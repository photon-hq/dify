# Privacy policy

Effective date: October 22, 2026

This Photon Trigger provider for Dify processes the selected Photon environment (origin), API key, and project ID; the Dify endpoint of each subscription; the ID and signing secret of the Photon webhook destination it creates; and the received messages Photon delivers: message, space, and user identifiers, platforms, message content, the handles and identifiers of senders and of the project's receiving lines and accounts, status, and timestamps. These values can include personal data: message content, phone numbers, email addresses, and the platform identifiers of people who message the project on iMessage, SMS, WhatsApp, WhatsApp Business, email, or Telegram.

Dify stores the configured environment, API key, and project ID with the subscription, and the destination ID and signing secret as the subscription's properties, the signing secret as a secret. The plugin holds deliveries in memory while it checks their signature and passes the message to Dify as the workflow's variables, and persists nothing: no files, database records, message cache, or plugin storage. It does not collect analytics, log credentials, log complete request headers, or log message content. The plugin has no retention period of its own; transient data lasts only as long as the request.

To check the API key, and to create and delete a subscription's webhook destination, the plugin transmits data only to the selected Photon origin over verified HTTPS: **https://api.photon.codes** for production, or **https://api.staging.photon.codes** for staging. These are the only two accepted origins. The API key is sent as a Bearer authorization credential, and the project ID scopes the request. Creating a destination transmits the subscription's Dify endpoint, the destination name `Dify`, the API version, the `message.received` event, and an idempotency key; Photon returns the destination and its signing secret. Deleting it transmits the destination ID. Errors carry Photon's HTTP status, error code, and stated reason; the plugin never returns the API key or HTTP headers.

Photon processes and may retain the transmitted data, and the messages it delivers, under [Photon's privacy policy](https://photon.codes/privacy-policy). The plugin does not control Photon's retention. Photon receives the messages from the network of each space's channel: Apple for iMessage ([Apple privacy policy](https://www.apple.com/legal/privacy/)), mobile carriers for SMS, Meta for WhatsApp and WhatsApp Business ([WhatsApp privacy policy](https://www.whatsapp.com/legal/privacy-policy)), Telegram ([Telegram privacy policy](https://telegram.org/privacy)), and the senders' email providers for email. The plugin itself contacts only the Photon API. Dify's deployment settings and policies determine retention of subscriptions, workflow inputs and outputs, execution histories, and logs.

There is no plugin-managed user-data collection, third-party analytics, advertising, or sale of data. Uninstalling the plugin does not erase data retained by Dify, Photon, or channel operators; delete the subscriptions first to delete their Photon webhook destinations, and use those services' controls and policies.
